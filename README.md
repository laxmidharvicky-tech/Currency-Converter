# 💱 Currency Converter

A simple, responsive, and user-friendly **Currency Converter Web Application** built using **HTML, CSS, and JavaScript**.

The application uses the **ExchangeRate-API** to fetch the latest exchange rates and convert an amount from one currency to another.

---

## 🚀 Features

* 💰 Convert currencies in real time
* 🌍 Supports a large number of international currencies
* 🔄 Swap "From" and "To" currencies
* ⌨️ Press **Enter** to convert
* 📊 Displays the current exchange rate
* 💵 Formats converted amounts to 2 decimal places
* 📱 Responsive user interface
* ⚡ Fast API-based conversion
* ❌ Input validation for invalid or empty amounts
* 🔐 API error handling
* 🌙 Dark mode

---

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3 / Tailwind CSS** — Styling and responsive design
* **JavaScript (ES6+)** — Application logic and API integration
* **ExchangeRate-API** — Currency exchange-rate data
* **Fetch API** — Making HTTP requests

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd currency-converter
```

### 3. Add your API key

Open:

```text
script.js
```

and replace:

```javascript
const API_KEY = "YOUR_API_KEY";
```

with your API key.

### 4. Run the application

Simply open:

```text
index.html
```

in your browser.

For a better development experience, use **VS Code + Live Server**.
